FinanceLens Audit Report

Türkiye odaklı kişisel finans takip uygulamasının 2026-08-24 tarihli tam kapsamlı incelemesi: bulunan hatalar, uygulanan düzeltmeler, mimari ve yol haritası. Tüm bulgular bağımsız inceleme ajanları tarafından denetlendi; her düzeltme birim testiyle kilitlendi.

Genel Bakış

FinanceLens; hisse senedi, ETF, eurobond, altın, gümüş, nakit, gelir ve giderleri tek panoda birleştiren, tüm değerleri canlı kur ile TRY'a normalize eden bir kişisel finans izleyicisidir. Next.js 16 frontend + NestJS 11 API monorepo olarak yapılandırılmıştır.

Ne yaptık?

Üç bağımsız inceleme ajanının bulduğu 36 bulgunun 25'i düzeltildi; kalan 11 açık kalem bilinçli olarak bırakıldı (4'ü tasarım kararı, 7'si küçük kalıntı — ayrılar Bulgular ve Yol Haritası sekmelerinde). Düzeltilenler arasında yanlış troy-ons sabiti (altın/gümüş gram fiyatı %9 sapmalıydı), üç farklı eurobond değerleme formülü, FX dönüşümü olmayan net değer toplamı, çapraz kiracı erişimi, yarış koşullu auth guard, atomik olmayan yazma işlemleri, doğrulanmamış sorgu parametreleri, kırık demo (mock) modu, beş farklı para formatlayıcısı, bozuk dark mode ve eksik mobil navigasyon var. Her düzeltmeye eşlik eden testlerle birlikte CI artık her push'ta lint + test + build çalıştırıyor.

Ardından ürün kimliği yenilendi (zümrüt marka token sistemi, tema-duyarlı grafikler, yeni landing sayfası) ve dokümantasyon seti (README, AGENTS.md, CONTRIBUTING, ajan skill dosyası) sıfırdan doğrulandı. Detaylar Bulgular sekmesinde.

pnpm test                             # api jest + web vitest

Demo modu için apps/web/.env.local içinde NEXT_PUBLIC_USE_MOCK_DATA=true — gerçek veritabanına dokunmadan tüm ekranlar sahte veriyle çalışır.

Bulgular

Denetimden çıkan tüm maddeler alan bazında gruplandırıldı. Durumlar düzeltme sonrası gerçeği yansıtır: FIXED düzeltildi ve testle kilitlendi, OPEN tasarım kararıyla ertelendi veya küçük kalıntıdır.

Mimari

Turborepo monorepo: web (:3000) → api (:3001, global /api prefix) → Supabase (PostgreSQL + Auth) ve Yahoo Finance (fiyat + FX). Demo modunda istemci katmanı ağ çağrısı yapmadan yerel mock state'e düşer.

FX normalizasyonuDashboard overview tüm USD/EUR pozisyonlarını getFxRate() ile TRY'a çevirir; yanıt fxRates ve bayat kur uyarıları içerir.
Çok kiracılılıkHer yazma işlemi { id, userId } filtresiyle atomik updateMany/deleteMany; etkilenen satır 0 ise 404.
GüvenlikGlobal APP_GUARD JWT zorunlu (yalnızca health public), helmet, sanitize edilmiş hata gövdeleri, prod'da kapalı Swagger.
Demo moduEnv flag'i ile REST istemci yerine mock katmanı: aynı enum'lar, kalıcı CRUD, sıfır altyapı gereksinimi.

CI Hattı — .github/workflows/ci.yml

Node 22 üzerinde iki paralel job: web (kurulum → prisma generate → check-types → lint → test → build) ve api (kurulum → prisma generate → lint → test → build). Kök gate'i yerelde aynen tekrarlar: 

pnpm lint && pnpm check-types && pnpm test && pnpm build

Bu raporun yazıldığı dalda dördü de yeşildir: 139 + 57 = 196 test geçti, lint sıfır uyarı politikası (--max-warnings 0), tip kontrolü temiz, üç uygulama da derleniyor.
